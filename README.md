# EauPartagée

PWA mobile-first, utilisable hors ligne, qui suit les remplacements de bonbonnes d'eau
Odezil d'un foyer, répartit chaque livraison entre deux foyers et calcule ce que le
second foyer doit. Le second foyer consulte une page en lecture seule via un lien privé.

Projet en cours de construction : voir [`docs/PLAN.md`](docs/PLAN.md) pour le plan
et [`CLAUDE.md`](CLAUDE.md) pour les conventions et les règles de sécurité. Le guide
d'installation complet (Supabase, Google, Vercel, installation sur téléphone) arrive
avec la dernière étape.

```bash
npm install
cp .env.example .env.local   # puis renseigner les valeurs
npm run dev
```
